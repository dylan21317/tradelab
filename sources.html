Sources de données

Cette page explique comment brancher une source de données sur le site. Aucune n’est branchée pour l’instant.

Brancher une source

  1. Choisir un service

    Prenez un service de données de marché qui fournit un code d’intégration à copier, le plus souvent une balise <iframe>.

  2. Repérer l’emplacement

    Dans index.html, chaque cadre pointillé est un <div class="slot" data-slot="…">. Le nom est donné dans le tableau ci-dessous.

  3. Coller le code

    Remplacez le texte du cadre par le code du service, puis rechargez la page. Le cadre prend alors la forme du contenu collé.

Limite du HTML et du CSS seuls. Ils ne peuvent pas interroger une API pour en lire les données. Seul un code d’intégration fourni par le service, qui affiche lui-même ses données, fonctionne sans JavaScript. Vérifiez aussi les conditions d’utilisation du service avant de l’intégrer.
